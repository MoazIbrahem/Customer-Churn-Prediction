# 📉 Customer Churn Prediction Project

This project provides a complete system for predicting customer churn using **Machine Learning** and **Data Analysis** techniques. It includes a full pipeline starting from data preprocessing and feature engineering to model training and an interactive GUI application.

---

## 📝 Problem Definition

Customer churn is one of the biggest challenges faced by companies and businesses. Losing customers directly impacts revenue and growth, making churn prediction essential for improving customer retention strategies.

Challenges addressed by this project:

* Handling missing and inconsistent customer data.
* Processing categorical and numerical features efficiently.
* Extracting meaningful patterns from customer behavior.
* Building an accurate predictive model for churn classification.
* Providing an easy-to-use graphical interface for users.

## 🎯 Objective

Develop an intelligent system capable of analyzing customer data, preprocessing it, engineering useful features, and predicting whether a customer is likely to churn or not using Machine Learning techniques.

* **Backend / Processing:** Python

## ⚙️ Development Pipeline

### 🔍 1. Exploratory Data Analysis (EDA)

* Analyzing customer behavior and churn distribution.
* Detecting missing values and outliers.
* Visualizing relationships between features and churn status.
* Understanding feature importance and correlations.

### 🛠️ 2. Data Preprocessing

* Handling missing values.
* Encoding categorical variables.
* Feature scaling and normalization.
* Removing duplicates and noisy data.
* Splitting data into training and testing sets.

### ⚡ 3. Feature Engineering

* Creating new meaningful features from existing customer data.
* Transforming categorical and numerical attributes.
* Selecting important features to improve model performance.
* Reducing irrelevant or redundant information.

### 🚀 4. Model Training

* Training Machine Learning classification models.
* Evaluating multiple algorithms for best performance.
* Hyperparameter tuning and optimization.
* Saving the best trained model for deployment.

### 📊 5. Evaluation

* Measuring Accuracy, Precision, Recall, and F1-Score.
* Generating Confusion Matrix and Classification Reports.
* Comparing model performance on training and testing datasets.

### 🖥️ 6. GUI Application

* Interactive graphical interface for users.
* Uploading customer datasets easily.
* Running predictions directly from the GUI.
* Displaying churn prediction results clearly.

## ▶️ How to Run

> 💡 **Important Note:** Install all required libraries before starting:
>
> ```bash
> pip install -r requirements.txt
> ```

### 1️⃣ Step 1: Open the Project

* Download or clone the project files to your computer.

### 2️⃣ Step 2: Run the Application

* Open the terminal inside the project folder.
* Run the following command:

```bash
python app.py
```

### 3️⃣ Step 3: Open the Website

* After running the application, a local URL will appear in the terminal.
* Hold `Ctrl` and click on the URL to open the website in your browser.
